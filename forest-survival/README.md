# 🌲 Түнкү Токой

«Oh Deer» сыяктуу көп оюнчулуу жашынмак оюну — Three.js менен жазылган,
телефондун браузеринде **альбомдук (горизонталдуу)** көрүнүштө иштейт.
iPhone да, Android да, компьютер да бирдей ойнойт.

---

## Сюжет

Токойдо **10 бот бугу** жүрөт. Алардын арасында **оюнчу-бугулар** жашынган.
Бир оюнчу — **мергенчи**. Мергенчи «кайсынысы адамча кыймылдап жатат?» деп
аңдыйт, бугулар болсо бот бугулардан айырмасы билинбесин деп аракет кылат.

| Этап | Эмне болот |
|---|---|
| **1. Капас** | Мергенчи 15 секунд капаста турат. Бугулар жашынып үлгүрөт. |
| **2. Күндүз** | Мергенчи чыгат. Акыл-эси (Sanity) жай түшүп турат. |
| **3. Түн** | **Акыл-эс нөлгө түшкөндө** токой 2 секундда кескин караңгы болот, ай чыгат. |
| **4. Вендиго** | Тирүү бугулар **эки бутуна туруп** вендигого айланат. Эми ОЛОР аңчы. |
| **5. Үй** | Түндө картада үй пайда болот — мергенчинин жалгыз кутулуу жолу. |

**Мергенчи жеңет** — бардык оюнчу-бугуну атса, же түндө үйгө жетсе.
**Бугулар жеңет** — вендиго болуп мергенчини кармаса, же таң атканга чейин аман калса.

### 🦌 Бугу
- **Ачкачылык** түшүп турат → ✋ менен козу карын же. Жегенде **кырсылдаган үн**
  чыгат, мергенчи ошол жерди көрөт.
- Курсагың бош калса — **корулдап** ордуңду ачып берет, дагы жай басасың.
- **🌿 Оттоо** — башыңды ийип оттойсуң, бот бугудан эч айырмаң калбайт.
- **⚠️ Секирүү** — бот бугулар секире албайт! Секирсең мергенчи дароо байкайт.
- **💨** — мергенчини алаксытат (8 секундда бир).
- Көп чуркасаң байкалып каласың.
- Мергенчи сага **ак элес** болуп көрүнүп турат — таштын, дарактын артында
  болсо да. Кайда экенин билип, тескери жакка жүр.

### 🏹 Мергенчи
- **15 жебе**. Атылган жебе ~7 секундда кайра келет.
- **Акыл-эс (Sanity)** убакыт өткөн сайын жай түшөт, **чуркасаң тезирээк**.
- **Жаңылып бот бугуну атсаң — акыл-эс кескин түшөт (−20).** Ошондуктан
  ишенбей атпа.
- Оюнчу-бугуну атсаң калыбына келет (+25).
- **6 trail cam** 📷 — коюп кетсең, 180° бурчта кыймыл байкаса кабар берет.
- **Жаа эки кадам**: 🏹 бир басканда тартылат жана даяр турат → экинчи
  басканда атылат. Тартылып турганда жай басасың — даярданып көздө.
- Акыл-эсиң нөлгө түшсө — түн кирет жана сен олжо болуп каласың. **Үйгө жүгүр.**

### 🩸 Вендиго
Бугунун денеси эки бутуна турат, кызыл аура жанат, ылдам чуркайт.
🩸 менен мергенчини чабасың.

**Жалгыз ойногондо мергенчи болсоң:** түн киргенде сен таппай калган бугулар
жерден көтөрүлүп вендигого айланат жана сени кубалай баштайт. Аларды
**өлтүрүүгө болбойт** — жебе тийсе 1.6 секунд гана токтойт.
Вендиголор сенден **ылдам** — качып кутула албайсың, дарак-таштарды колдонуп
адаштырыш керек (чыныгы оюндагыдай).

**⚠️ Бир сокку = өлүм.** Вендиго жеткенде кино башталат: камера кескин ага
бурулат, экран титирейт, вендиго каптап келет, анан адам жерге кулайт.

### ⛰️ Таштын үстү — убактылуу коопсуз жер
- Чоң таштын жанында **⤒ секирүү** баскычын бассаң — үстүнө чыгасың
  (2.6 метрге чейин бийик ташка).
- Үстүндө турганда **вендиго сени кармай албайт** — астыңда күтүп турат.
- Бирок **5 секунд гана** тура аласың: убакыт бүтсө өзүң түшүп каласың
  жана ошол ташка 3 секунд кайра чыга албайсың.
- Экранда калган убакыт көрүнүп турат.

### ⏸ Түн киргендеги 3 секунд
Вендиголор жерден көтөрүлгөндөн кийин **3 секунд катып турат** — ушул убакытта
мергенчи качып үлгүрүшү керек. (Онлайнда да ошондой: вендигого айланган
оюнчу 3 секунд кыймылдай албайт, бирок айланасын карай алат.)

### 🏚️ Үй (cabin)
Түн киргенде картада үй пайда болот — мергенчинин жалгыз кутулуу жолу.

- **Мергенчиден эң кеминде 72 метр алыс** жерде пайда болот, ошондуктан
  «жанында туруп алуу» мүмкүн эмес.
- Асманга чыккан **кызыл мамы** менен белгиленет — дарактын артынан да көрүнөт.
- Эшикти ачууга **1.8 секунд** керек, заматта кирип кетпейсиң.
- **Вендиголор да үйдү көрөт** — мергенчи жакындаса, алар түз артынан
  кубалабай, **эшиктин алдын тосот**.

## Үн

Бир дагы аудио файл жок — музыка жана бардык үндөр **Web Audio менен коддон
жаратылат** (`js/audio.js`).

- **Күндүз** — жумшак пентатоника, куштардын сайраганы, шамал
- **Түн** — төмөнкү коркунучтуу дрон, жүрөк кагуу (коркунуч жакындаган сайын
  тездейт), үкү, бутак сынуу, алыскы үшкүрүк, шыбыш
- **Түн киргенде** — чоң horror сокку (жогорулаган ызы-чуу → удар → кыйкырган
  струналар), андан соң вендигонун кыйкырыгы
- Эффекттер: жаа тартуу/атуу, жебенин учушу, тийүү, кадам (туяк жана өтүк
  башкача), козу карын кырсылдоо, курсак корулдоо, 💨, камера, жеңиш/жеңилүү

🔊 баскычы менен (же `M` баскычы) өчүрсө болот.

## Трейлер

Оюн биринчи ачылганда **▶ БАШТОО** баскычын басасың (браузер үн чыгарууга
уруксат бериши үчүн керек), андан соң ~17 секунддук кино ойнолот:
токой → бугулар → мергенчи жааны тартат → **түн кескин кирет** → вендиго
жерден көтөрүлүп каптайт → аталышы.

«Өткөрүп жиберүү ▸» баскычы бар. Башкы менюдан **🎬 Трейлер** деп кайра
көрсө болот. Коду `js/intro.js` ичинде — кадрлардын тизмеси, ар биринин
узундугу жана текстери ошол жерде.

|---|---|---|

## 🌍 Ноутбуксуз: Firebase'ге коюу

Ноутбук күйгүзбөй эле, интернет аркылуу досторуң менен ойноо үчүн.

### 1. Firebase долбоорун түзүү
1. https://console.firebase.google.com → **Add project** → ат бер
2. Сол менюдан **Build → Realtime Database → Create Database**
   · регион тандап, **Start in test mode** десең эле болот
3. ⚙️ **Project settings → Your apps → `</>` (Web) → Register app**
4. Чыккан `firebaseConfig` объектин көчүрүп, **`js/firebase-config.js`**
   ичине кой. `databaseURL` сөзсүз болсун
   (`https://...firebasedatabase.app`).

### 2. Коюу (deploy)
```bash
npm install -g firebase-tools     # бир жолу
firebase login
firebase init hosting             # "Use an existing project" → долбооруңду танда
                                  # public directory: .   (чекит)
                                  # single-page app: No
firebase deploy
```

Даяр — `https://сенин-долбооруң.web.app` деген дарек чыгат. Ошону досторуңа
жөнөт, телефондон ачып ойной беришет. **Ноутбук өчүк турса да иштейт.**

Эгер `firebase init` суроолорду берип убара кылса, долбоордо даяр
`firebase.json` жана `database.rules.json` бар — `firebase use --add` менен
долбоорду тандап, түз эле `firebase deploy` десең болот.

### 3. Коопсуздук жөнүндө
`database.rules.json` ичиндеги эрежелер `rooms` бутагын ачык кылат — шилтемени
билген ар ким бөлмө түзө алат. Достор менен ойноого жетиштүү, бирок ага
маанилүү эч нерсе сактаба.

## 2. Команда менен ойноо (Wi-Fi)

Сервер **таза Node.js**те жазылган — `npm install` кылуунун кереги жок.

```bash
cd forest-survival
node server.js
```

Терминалда мындай чыгат:

```
  🌲  ТҮНКҮ ТОКОЙ сервери иштеп жатат
  Ушул компьютерде : http://localhost:8080
  Телефондон кир   :
      http://192.168.0.105:8080
```

Эми **телефондордон** ошол `http://192.168.0.105:8080` дарегине кир
(сандар сеникинде башкача болот). Телефон менен компьютер **бир Wi-Fi'да**
болушу керек.

- iPhone — Safari
- Android — Chrome

### Достор кантип кошулат — кадам-кадам

**Сен (хост):**
1. `node server.js` иштет (бир гана компьютерде).
2. Оюнду ач → **👥 КОМАНДА МЕНЕН** → атыңды жаз → **🏠 БӨЛМӨ ТҮЗҮҮ**.
3. Экранда чоң **бөлмө коду** (мис. `UFRJ`), **QR код** жана **шилтеме** чыгат.

**Досторуң:**
4. Телефондун **камерасын QR кодго** кармайт → шилтеме ачылат.
   *(Же шилтемени WhatsApp менен жиберсең болот — «📋 Көчүрүү» баскычы бар.)*
5. Оюн ачылгандан кийин: **👥 КОМАНДА МЕНЕН** → атын жазат →
   **🚪 БӨЛМӨГӨ КИРҮҮ** → сенин **кодуңду** жазат → **КОШУЛУУ**.

**Чогуу:**
6. Хост (★) **БАШТОО** баскычын басат.
7. 🎲 **Мергенчи кокустан тандалат** — ролду эч ким өзү тандабайт.
   Калганыңар бугу болосуңар.

Бөлмөдө 10 оюнчуга чейин (3–4 адам эң ыңгайлуу). iPhone — Safari,
Android — Chrome.

### 🎲 Мергенчи кантип тандалат
Чыныгы оюндагыдай — **кезек менен**. Мергенчи болуп бүткөн оюнчу, калгандардын
баары бир жолудан мергенчи болмоюнча кайра тандалбайт. Мисалы 3 оюнчуда:
`Достук → Бекзат → Орозбий → Бекзат → Орозбий → Достук → …`

Раунд бүткөндө **ДАГЫ ОЙНОО** басып бөлмөгө кайтасыңар, хост кайра БАШТОО
басат — жаңы мергенчи тандалат. Жыйынтык экранында ким мергенчи болгону
жазылып турат.

> **Wi-Fi жөнүндө.** Сервер сенин компьютериңде гана иштейт. Достор эч нерсе
> орнотпойт — алар жөн гана браузерден шилтемени ачат. Шарт бирөө: телефондор
> менен компьютер **бир эле Wi-Fi'га** туташкан болушу керек (бир үйдүн
> роутери, же телефондон таратылган hotspot). Мобилдик интернет аркылуу
> иштебейт.
>
> Оюн шилтемени өзү түзөт: `localhost` деп ачсаң да, серверден чыныгы
> Wi-Fi дарегин (мис. `192.168.0.105`) сурап алып көрсөтөт.

> Телефон кошулбаса — Windows брандмауэри 8080 портун жаап жаткан болушу
> мүмкүн. Биринчи жолу `node server.js` иштеткенде чыккан терезеде
> **«Жеке тармактар» (Private networks)** дегенге уруксат бер.

> Эгер телефон кошулбаса: компьютериңдин брандмауэри 8080 портун жабып
> жаткан болушу мүмкүн. Windows'то Node.js'ке «Жеке тармактарда» уруксат бер.

## 5. Жөндөө

Баары `js/config.js` ичинде:

```js
round.cageTime: 15      // мергенчи капаста канча секунд турат
round.dayTime: 240      // күндүз эң көп канча созулат
round.nightTime: 90     // түн канча созулат
round.nightFade: 2.0    // ⚡ түн канча секундда кирет
round.npcDeer: 10       // бот бугулардын саны
round.botTargets: 3     // жалгыз ойноодо мергенчи издей турган бугулар

hunter.maxArrows: 15          // жебенин саны
hunter.wrongShotPenalty: 20   // жаңылганда акыл-эс канча түшөт
hunter.sprintSanityDrain: 1.8 // чуркаганда акыл-эс канча түшөт
cam.count: 6                  // trail cam
cabin.minDist: 72             // үй мергенчиден канча алыс пайда болот
```
