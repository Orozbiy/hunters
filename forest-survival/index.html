⚠️ Оюн сервери иштебей жатат

Бул барак Live Server (же башка жөнөкөй сервер) аркылуу ачылган окшойт. Ал файлдарды гана берет — команда менен ойноо үчүн оюндун өз сервери керек.

1 VS Code'до: Terminal → New Terminal
2 Жаз: node server.js
3 Терминал берген дарек менен ач: http://localhost:8080

⚡ Быстрая игра Live Server менен да иштей берет — серверди талап кылбайт.

📶 Wi-Fi кантип иштейт
1 Сервер бир компьютерде иштейт: node server.js
2 Телефондордун баары ошол эле Wi-Fi'да болушу керек
3 Досторуң эч нерсе орнотпойт — браузерден шилтемени ачат
Досуң берген бөлмө кодун жаз:
Эгер «байланыш жок» десе — хосттун компьютеринде node server.js иштеп турганын жана экөөң бир Wi-Fi'да экениңди текшер.

ЭРЕЖЕ
🦌 Бугу

Сен 10 бот бугунун арасындасың. Мергенчи «кайсынысы адам?» деп аңдыйт. Бот бугулардай жүр: оттоп тур, акырын бас. Көп чуркасаң байкалып каласың.

Ачкачылык түшүп турат — ✋ менен козу карын же. Ачка калсаң жай басасың.

💨 — мергенчини башка жакка алаксытат.

🏹 Мергенчи

Раунд башталганда 15 секунд капаста турасың. Чыккандан кийин оюнчу-бугуларды таап атышың керек.

Акыл-эс (Sanity) жай түшөт. Жаңылып бот бугуну атсаң — кескин түшөт. Нөл болсо — бугулар вендигого айланып сени аңдыйт.

🏹 бир басканда жаа тартылат, экинчи басканда атылат.

🌑 Түн

Белгиленген убакта токой 2 секундда кескин караңгы болот. Жаркыраган өсүмдүктөр гана көрүнөт.

Бугулар таңга чейин аман калса — бугулар жеңет.
